## 前工程DIとDJで何を変えたか

DIは峡谷風の奥行きを実装したが、実走行視界では15秒の斜め棚・梁、17秒の遠景圧縮、18.5秒の画面上端切れでART REJECT。DJはその反省から **新しい都市建築を追加しなかった**。先に高速カメラによる「遠景→接近→通過」の視覚上の物語を、従来の15.0／17.0／18.5秒の3時点より細かく検証した。

**証拠撮影**：真のB48実道路7、B51-C実動体28、gap52、240Hz P96 scripted start00走行から、14.0、14.5、15.0、15.5、16.0、16.5、17.0、17.5、18.0、18.5秒の10点を計測し、true-pinch / pinch-switch各10枚＝計20枚の本物のゲームWebGL2キャンバスを撮影。0.5秒間隔で抽出した静止画であり、**240fps動画や人間操作動画ではない**。正規カメラを別角度に変更せず、実ゲーム内の視界での知覚が対象。

これを実現するため、専用 `scripts/p101-w9c2-g4e7dj-native-storyboard.mjs` は既存BGと同一Runner／運動法則／native cameraを用い、サンプル時点のみ追加。通常の `web/drive3d.mjs` には一切コミット変更せず、Playwrightの**PRIVATEテストページ内だけ**で追加サンプルIDのallowlistを一時的に置換し、生成した正規カメラJSONだけをテストページへ供給。既存CX用の15秒・17秒のカメラが配列先頭2つになるよう順序維持し、**CXジェネレータそのもの、既存の2つの主役の採択地点、およびゲームのコライダーを変更しない**。正規BG3時点のRunnerスナップショット構造はtrue-pinch/pinch-switch双方で元ファイルとdeepEqual完全一致。別試行の前DI Artifact #12694960144の6枚の共通正規CX WebGL PNGと、新DJの15/17/18.5秒PNGは **6/6 SHA-256バイト完全一致**（CIから取得した両Artifactを独立比較）。そのため連続サンプルによりゲーム視界が書き換わったとの解釈は禁止。

## 画像上の知見（目視による、数値ARTスコアではない）

| 時点 | 正規ゲーム視界での構図 |
|---|---|
| 14.0–14.5 s | 道路左手に巨大な低い構造／近接街区が迫る。別の遠景主役も見えるが、同じ都市の階層や居住活動としては不明瞭。 |
| 15.0 s | 主役クレセント系の大きな建築が画面左で非常に強い存在感。右／遠方の主役は小さく、前後の接続性はまだ弱い。 |
| 15.5 s | 左の巨大主役の多くが画面左上へ裁断され、建築の全貌が読みづらい。 |
| 16.0 s | 先ほどの大主役はほとんど消える。一方、前方の街区と主役は相対的に小さく、**都市の壮大さが途切れる中間区間**。 |
| 16.5–17.0 s | 前方の主役と街区が目立つが、道路沿いの公共空間・居住部分・遠方の巨大主役を一つの都市として認識できない。 |
| 17.5–18.0 s | カメラには道路主面が画面端へ寄り、黒い空間・上方の建築の占有が大きくなっていく。画像だけで人間の公平性や接地状態を認定しない。 |
| 18.5 s | 以前からのBG指定によるoff-road診断画角。通常レース進行の美術採用の肯定例として扱わない。 |

この差は両道路の10枚比較でほぼ同方向。特に**15.5–16.5秒の視覚的な橋渡しが欠けていること**は、従来の3画角だけを見ていたときより直接に観察できた。現行CXが比較基準として安定していることと、都市美術の正式品質が高いことは別である。

## 次DK工程の「作る対象」をここで固定

**視覚目的**：既存の左近景主役が画角から去る15.5秒以後、次の都市のまとまりが見える16.5～17.0秒まで、同一都市の建築階層と奥行きが連続して変わる経験を作る。

**形状ではなく画面構成の要求**：1) 15.0秒の印象的な輪郭と安全な道路先読みは壊さない、2) 15.5～16.5秒に空白や単一の棚・薄い柱しか見えない中間地点をなくす、3) 16.5～17.0秒に都市交通・公共空洞・中景居住地・主役が同じ構造だとわかる、4) 誇張した画角・偽コライダー・新道路を禁止。過去のDA（板壁）、DB（棒）、DC（棚）、DG（箱）、DH（充填楔）、DI（遠景峡谷）の形だけを組み合わせるのは禁止。

**候補方向の比較**：A「連続した都市基盤が空中へ立ち上がる立体湾岸」—都市のひとつの母体が複数の異なる高さの大空洞を生む。B「谷に向かい積み重なる斜めの居住街路」—近景から遠景へ自然に視線を渡す。ただし斜めの棚状になる危険が高い。C「街区密度が変化する非対称の居住リング都市」—再び独立リング装飾化する危険が高い。**推奨はAを優先研究**。どれも美術採用は未認定。次はこれ以上監査道具を作り込むのではなく、15.5／16.0／16.5秒を重視した一体都市構図をPRIVATE実3Dで一候補制作し、正規WebGLを比較、厳しい美術審査を行う。単なるパーツ追加は行わない。
