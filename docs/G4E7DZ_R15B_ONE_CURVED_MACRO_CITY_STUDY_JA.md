# R15B — ONE CURVED MACRO-CITY: 真正原ゲームに沿う都市全体の大質量・主空洞（試作）

## 制作目的／前工程との差
R14Dの32×36×36m単体建築は、真正画像で15〜17秒の存在感が消失した（ART REJECT）。R11の三つの巨大壁には元CX交差と生活空間の見えなさがあった。R15Bはこれらの案を装飾するのではなく、元ゲームで11〜17秒に実際に進行方向が変化することを前提に、**全時系列へ追従する一つの非反復的な都市地形**を研究する。

今回の対象は**新しいゲームステージや正式アートではなく、原物に対応した編集可能Blender研究候補1つのみ**。既存ゲームの操舵、速度、当たり判定、カメラ、本番URL、main、Gold、P100は変更しない。原プレイヤーの走路は変更せず、両道路の本物の240Hz位置から同一の世界座標に共有外側都市地形を構築する。

## 新造形の研究設計
1. R1のtrue-pinch／pinch-switchの11〜17秒、7代表時点×2を平均した道路の曲線を**世界座標で一度だけ**利用する（各道路に異なる都市を後付けしない）。
2. 曲線に沿う広幅の地形幹線、公開通路の候補、三つの非対称巨大量塊と空に開く公共空洞を本物の厚みのあるBlender閉じたメッシュで造形する。
3. 居住の奥行き、広いギャラリー、交通層、庭園などの意味ある立体構造を新しい3Dメッシュとして作る。単なる窓テクスチャ、反復門、細い支柱、遠い32m箱の配置には戻らない。
4. 大質量が巨大な無地の壁に見える／近景の危険を隠す／画面内で都市空間を読めないなら **ART REJECT**。地形幹線が見えても歩けることは未証明。

## 技術・美術判定を分ける
- 原R1編集Blender、13時点元カメラ、原CX18／B48実三角面7、B51元実姿勢13時点、28基×721tickの保守包囲JSONを使用。7代表時点×両道路14画像、編集BLEND×2、BVH結果をArtifactに保存する。
- 元道路と交差があれば安全研究として **不合格**。交差ゼロでもゲーム統合・連続時刻安全にはならない。元ソース全体の同一性も検査。
- 228本の原カメラレイ、主空洞3高度×3場所×13時点で視界を機械検査。ただし美しさやWebGLの画面品質を自動PASSにはしない。
- 後段で実画像を同じ時間軸のR1／R11／R14と比較。良い新候補が成立するまでは新しい小案を無制限に作らない。
- **工学的荷重認定、実入口、通行可能な床と階間経路、プレイヤーの試走、実WebGL、実FPSはすべて未評価**。
