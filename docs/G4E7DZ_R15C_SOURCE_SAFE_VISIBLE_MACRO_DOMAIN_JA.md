# DOPAGAKI SLOPE — R15C：巨大造形の前に元ソースの可視×安全の共通空間を確かめる

## なぜR15Cを行うか
R15Bの新規約605mの一体都市は、真正Blender37メッシュで生成成功したにもかかわらず、両道路で元CXとの実三角面交差16組・B51動体721tick保守包囲重複3組・新都市初ヒット平均2%程度・17秒完全消失だった。新しい巨大3Dを量産するだけでは原ゲームの良さに結びつかない。

R15Cでは新しいアートモデルを1個も作らず、先に実走行とカメラの「両道路で同じ座標の安全かつ見える設計空間」を探す。R14Bで実証した共有立地を正規の出発点にすることで、以前の問題だった2道路の位置ずらしや架空の安全を防ぐ。

## まとめて実行する四つの検証
- **C1 原データの再利用と保護:** R1の元240Hz start00／P96／13時点×両道路、編集可能な真正Blender、CX18、B48実物理7、B51 28基×721tick保守的AABB、R14B共通元世界立地を使う。ソースblob af076d67492a677d2235e4730aef8cdf4808e106を固定。
- **C2 安全体積の段階スケーリング:** R14Bの両道路同一座標の元安全立地（前4／中5／後9）を参照し、各立地の元サイズ＋48×48×48m、72×60×64m、96×72×80mに拡張した試験体積を、両道路の元CX/B48 BVH三角交差・元メッシュ頂点の体積包含・B51保守AABBに照合。安全判定のない大規模地形を600m一括で引かない。
- **C3 元カメラ連続視野・動体予告遮蔽:** 安全体積だけに対して内部27点の元カメラ正規13時点×両道路の実CX/B48/B51遮蔽を検査。両道路の**同時刻5連続（0.5秒刻み、最初と最後で2秒）**に3点以上見えることを最低研究条件とする。元B51中心への「現速度で直線距離換算約2.3秒以内・視界内・元物で遮蔽されない」レイを新しい体積が遮る候補も除外する。ただしこれは真の2秒前予告の証明にはならない。
- **C4 断片間候補の7点断面試験:** 近いEARLY→MIDDLE／MIDDLE→LATEの候補立地間で12×12×12mの断面を7内点で調べ、両道路すべての離散点で元物非干渉の候補だけを記録する。7点が安全でも連続経路・基礎・支持・歩ける床・本当の入口は**未認証**。結果を独立コードが再計算し、偽のART承認・偽立地・偽物理クリア注入を拒否する。

## データ解釈上の禁止事項
この工程は「造形前の調査」であり、探したAABBボックスは**新しい建築、実床、歩行ルート、ゲーム内コライダー、WebGL画面ではない**。遮蔽判定は原13標本、物理交差は元三角面や元頂点、B51は721tickの保守AABBであり、未標本時点や構造強度の連続安全を保証できない。候補なしはそのサイズと探索領域に限った結果で、世界全域に巨大建築が無理と結論してはならない。
