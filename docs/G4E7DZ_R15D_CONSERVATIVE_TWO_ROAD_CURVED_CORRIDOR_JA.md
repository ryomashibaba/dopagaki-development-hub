# DOPAGAKI R15D — 実原ゲーム2道路で非直線3D経路を探索し、全区間の保守体積を検証

## 前提：R15Cを真正な出発点にする
2026年10月28日 JST、R15C最終真正CI #40705855639 は Source TECH PASS。両道路同一世界座標＋寸法の66候補を実ソース監査し、31非干渉、16条件（9中心）で連続5カメラ標本＋B51中心レイの研究条件を通過。しかし24直線候補の7断面安全は0。これを解決せずに新しい巨大都市を建築しない。

R15DはR15C Artifactの確定原証拠だけを使い、最短EARLY→MIDDLEとMIDDLE→LATEの広い中庭を**本当に繋げる余地があるか**を、同一world XYZの非直線A*探索で試験する。目的は建築完成の主張ではなく、危険な単純直線案の失敗モードを解消する、造形前の根拠である。

## R15D 一括技術工程
1. **元物の保存と共通領域**：R1の元Blender両道路（CX18、B48実物理7、B51動体28、カメラ5、gap52、P96/240Hz）、R4の28基×721tick保守AABB、R15Cの実測JSONを使用。別々の道路で見せかけの移動や別モデルは作らない。
2. **研究対象の4接続**：R15CのEARLY E03→MIDDLE M01（約134m）、M01→M02、M02→LATE L03（約223m）、EARLY E03→M02の代替線。元のR15Cで共通空間・内部視界を検証済みの地点以外は接続終点に採用しない。
3. **単なる直線を禁止する非直線探索**：各接続で元進行方向12m刻み、左右±84m／上下±48mの世界空間を離散化。前進のほか同ステーションで左右・上下に移動できる3次元A*を使う。A*はこの範囲の空白を探すだけで、現実の地形生成・実床・支柱を作らない。
4. **原物理の区間全体の体積を検証**：研究用8m・12m幅の立体空間について、節点のキューブだけではなく**A*の各区間を覆う保守的な世界軸AABB**を両道路の真正CX/B48実三角面、元頂点包含証拠、B51全721tick包囲で検証する。斜め経路のAABBは実際の曲線チューブより広く、通れそうな場所を保守的に棄却することがある。
5. **偽陽性と偽承認の独立検査**：独立スクリプトはR15Cアンカーから元の世界座標を再計算し、A*グリッド上の連続、元二道路の各移動区間の証拠、経路長、8/12m断面を検算。元ゲームの変更、ゲーム導入、歩行可能な床、人体試遊、ART PASSを不正に主張した場合はFAILさせる。

## 成功・失敗の読み方
- 「元ゲーム両道路で研究用の空間が非交差」と言えるのは、元CX/B48メッシュとB51保守包囲について検索した体積のみ。これは**実際の建築物・通路・入口・支持床の保証ではない**。
- 負の探索結果はこの4接続・幅8/12m・左右±84m／上下±48mのグリッド内に限られる。斜めの保守AABBが大きいため、実際の曲がった通路の不可能性を証明するものではない。
- 検索した経路の全区間が安全でも、**元カメラで美しい都市が連続して見えるか／人間が歩ける交通／構造的支持／画面上の障害予告**は別ゲート。これらを認証する前にR15Dを「Slope2 DNAの完成」と呼んではならない。
- 造形についてはART-FIRSTを維持し、無地の巨大な壁、同形の小都市の反復、元画面に見えない建物の量産に戻らない。
