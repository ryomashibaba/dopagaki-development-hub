# R15F — 元ゲームカメラから逆算する巨大未来都市の成立候補領域

## 現状と方針
R15Dは幅12mまで保守的に安全な3D迂回経路を実証し、R15Eはその上に約414.545m・14メッシュの編集可能Blender交通構造を制作した。しかし真正14画像で新造形の元カメラ画面初ヒット平均true-pinch2.819%、pinch-switch2.757%、独立ART REJECT。原因はマクロ形態ではなく、まず**都市が正面の視野に入っていない**ことと、都市生活の読める主空洞を伴わない細い橋に留まること。

R15Fは既存の細い回廊に繰り返し窓を貼る改造を停止し、今度は真正元13カメラ・両道路のワールドXYZから逆に42×42×58mと76×64×84mの巨大研究用候補体積を配置し、現実に見える場所か、元CX/B48/B51との干渉がないか、オリジナルB51の前方危険物の視線を塞がないかを*先に*検索する。

## 一括技術内容
- 真のR1 240Hz元プレイヤー位置・前方向をtrue-pinch／pinch-switch平均して、11〜17秒の7起点、前方85/150/225m、左右50/100m、鉛直底部+18/+50m、2サイズの組み合わせから336仮説を一つの世界座標で列挙する。別道路へ都合良く後付けで動かさない。
- それぞれの元Blenderシーンで真正CX18/B48道路7のBVH三角面交差・元頂点包含とB51×28の元721tick保守AABBを検証。元13フレームのカメラと実B51姿勢から研究用体積内部6点の遮蔽を調査する。
- 元の障害物中心への正面視界を候補体積が塞いでしまう場合は拒否（速度換算約2.3秒内の幾何的前処理のみ。実際にプレイヤーが2秒前に回避できることの証明ではない）。B51本人の三角面を自己遮蔽として誤判定しない。
- **両道路の同時刻13標本中2回以上、同じ体積の6内点中最低2点が実物非遮蔽**であることを最低条件にする。EARLY/MIDDLE/LATE各エリアで基準2点以上可視の複数時点候補を抽出し、近すぎる候補は同一地点として65m以下の重複選択を排除。
- 独立別コードが336個・計測された両道路可視・既存元ソース一致・仮説が実都市でないことを検査し、偽ART・偽WebGL・偽ソースなどの承認を拒否する。

## 正確な限界と停止条件
これは**Blender研究用の直方体を探すだけで、まだ本当の3D建築・体積内の実床・巨大な主空洞・支持・原道路からの歩行経路は全く制作・認定していない**。元カメラ内部6点の見通しは実画像の占有率を測ったものではない。全部の立地を走査したわけでもなく、336仮説の結果だけで元ゲーム世界の不可能性を証明してはならない。

安全で目立ちそうな場所が見つかっても、単に巨大な無地の壁としてゲームの障害物や原有機的な景観を覆うリスクがある。次段階では、3Dの彫刻された公共／居住／交通構造、原道路・支持・入口の機能、元カメラ7時点の本物の美しい都市空間を別ゲートで試作・評価する。視認・安全が共に不成立なら、新しい表面ディテールは増やさない。

## R15F 真正最終結果・批判的再評価

**CI #40712198305 SUCCESS（元ソースBlender・独立QA含む）／Artifact #12826776538。**
