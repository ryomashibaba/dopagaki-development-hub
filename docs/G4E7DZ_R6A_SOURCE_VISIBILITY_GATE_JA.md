# G4E-7DZ R6A — 原CXの時間的視認と都市機能を分けるための検証（PRIVATE）

## 背景
R4の巨大地形はART REJECT、R5Bの元CX接点へつながる短床もART REJECT。R5Aの点接触が「公共・交通・居住の見える都市」と同義でない。さらなる巨大造形の量産は停止する。

## R6Aの新しい実制作
元DRの真正Blender .blend、元240Hzカメラ5、CX18、B48実道路7、B51移動体28、R5AのCX接点を**原物のまま**使用。両道路×15.5/16/16.5/17秒の8視点について、(1) 元景観のBlender実レンダ8枚、(2) 既存CX/B48/B51への64×40サンプル視線からなる解析マスク8枚、(3) 既存CXオブジェクト別の視野内サンプル数・距離帯・R5A端点投影を記録した監査JSON2件を作成する。色マスクは解析物であり、新都市をゲームWebGLに描画した画面ではない。レイ・サンプル数は美術評価点ではない。

## 設計方針の変更
以前の造形先行→カメラ確認という順序を廃止し、**現実のCX表面と道路が正規画角でどう入れ替わるか**を把握した上で、都市生活の公共床・交通・住宅と、見える深さ・見えなくなる時刻・道路の危険認知が両立する**一つの都市断面**を設計する。見えない機能の詳細化は禁止。CXの見えている表面に新しい薄板を加えても都市の内部にはならない。機能の判読は後続の実Blender小模型を目視し、人間QAは別に行う。
