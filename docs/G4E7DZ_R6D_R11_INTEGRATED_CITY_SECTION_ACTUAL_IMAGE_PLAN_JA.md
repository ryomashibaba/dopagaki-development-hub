# R11 — 原物保護を維持した「ゲームで見える一体的な都市断面」再設計ゲート

R10Aの486サンプルでは、既存CX内の6×6×10m、元床・対向壁・空き体積を同時に満たすセル0件。R10Bでは約100mの橋梁に既存CX幾何学上の支持候補がtrue-pinch 3/15・pinch-switch 5/14のみ、しかも終点なし。R10Cはいずれも現在の立地・構成についてSTOP。これは調べた範囲の否定であり、新しく未来都市を構想すること自体の否定ではない。

## 基本方針の修正

R2〜R7は道路脇の小物・柱・門・反復フレームを重ねる失敗。R8〜R10は逆に既存CXの構造条件に引っ張られ、新たな本当の都市美術を作ることから離れた。**R11では既存物の不変更と、新都市が既存CXに支持されている必要性を切り離す。** ゲーム内架空都市は、新しく設計された自立・吊下げ・浮遊支持による大きな真の体積を使い得る。元B48実物理・B51動体・原カメラ・操舵などは不変更。ゲームプレイ安全と美術は別審査。

## 一度に進める具体工程

**R11A**：本当の原11〜17秒プレイヤー・正規カメラと元CX18/B48物理7/B51移動28から、早期11〜13秒、中央14〜15秒、出口16〜17秒のいずれも都市が画角外へ消えない、元物体と交差しない空間の**ボリューム制約**を整理。投影点が見えるだけのフェイクPASS禁止。

**R11B**：区域全体ではなく、最初は**一体的な都市のうち1つの「内部を移動しているように見える」断面**を設計。機能の異なる公共・住居・交通を実際の厚さと開口を持つ床・壁・支持・縦動線で関係づける。道路は既存物を固定。部品・高架線・壁を数だけ置かない。必要なら独立支持の形状を最初から全体と一緒に構想。

**R11C**：実Blender3D、同じ原11〜17秒×両道路14真正比較、元CX/B48実三角形交差、B51全28×721tick標本危険領域との関係、視認性・施設としての意味・原走行への危険を**一度に検査**。元ゲームWebGL・人間試遊は正式ART合格以降の別段階。CI SUCCESSでもART REJECTあり。

**失敗時停止条件**：既存CX/B48に侵入する／標本B51に衝突する／早期・後期で画角から都市が消える／巨大門・柱と棚の反復に戻る／「通過・居住・交通・公共」が原視点で区別不能、なら装飾による延命はしない。

**固定保護**：CX18／元B48実物理7／元B51移動28／原カメラ5／gap52、CX Git blob `af076d67492a677d2235e4730aef8cdf4808e106`、P96操舵・240Hz物理、Gold、P100、main、正式公開URLは変更禁止。新ゲームコライダー0。ART採用0、Slope2正式認定0m、HUMAN/GAMEPLAY/PERFORMANCE/INTEGRATION/RELEASE/MERGE HOLD、Draft PR#46未マージ。

**効率**：R1/R4のGitHub genuine source artifactsを再利用、設計・Blender実物・審査・採否・報告を極力一括で行う。テスト件数・メッシュ数・工程番号を価値とみなさない。必要な新しい成果は「元の走行で魅力的な都市空間が本当に見えること」。
