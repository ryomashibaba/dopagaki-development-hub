# R12：実カメラに見える「一つの生きた未来都市内部」を造形するための設計ゲート

R11初回は96編集メッシュで11秒の初ヒット約21%・17秒約3%／元CX交差12〜13組。R11-R1は99編集メッシュで17秒約10〜11%へ改善・元CX交差6〜8組に半減したが、11〜15秒は存在感が低下し、真正画像では巨大な斜めの壁・板で公共・居住・交通の内部空間が読めずART REJECT。

R12は**斜め壁にディテールを増やす修正版ではない**。R11の「道路左に3つの大きい中庭建築を分けて置く」構成をいったん停止する。

## R12A : 造形する前の真正World-and-Camera条件

原R1の11〜17秒×13正規カメラ時点、元CX18、B48物理7、B51動体28の全721tick標本を使用する。「見える」条件は実3D面への初ヒットだけでなく、公共空洞や住居室内へ本当にレイが通ること。原CX/B48の全三角形に設計体積が交差しないことを候補段階から強制する。早期11〜13秒・中間14〜15秒・末尾16〜17秒のバランスを保つ。複数時点の顔だけが見える偽連続は不可。

## R12B : 背景シルエットではなく、原路面から見える「住む都市内部」

- 公共・住居・交通を異なる箱や柱で表す代わりに、**一つの大きな人間スケールの断面**に、道路へ本当に開いた街区内の広場・部屋と窓・駅や交通アクセスを構造的に関係づける。
- 最初から元CXと非干渉を維持。ゲーム世界としての自立・懸架支持は研究可だが、実工学安全CERTIFIEDや原CXからの徒歩アクセスとは分ける。
- 手すり・デッキ・屋根の量産ではなく、見通し・陰影・住居の規模・交通の存在感が元ゲームカメラの第一印象で分かる構造を重視。
- 原B48の路面・幅、B51の実動体やP96原操舵を一切変えず、ゲームの見通し・障害物警告を遮らない。

## R12C : 本当に遊ぶ画面での美術採否（研究段階）

まず編集可能Blenderの元11〜17秒7時点×2道路の14真正PNGを作り、R1/R11/R11-R1との同視点4案比較、物理交差、空洞視線、モーション危険を独立判定する。大きさ・色・RGB差・CI成功は美術合格ではない。人間ゲームプレイ・PERFORMANCE・原WebGLへの統合はART通過後の独立ゲート。成功しなければ現案をREJECTにして装飾しない。
