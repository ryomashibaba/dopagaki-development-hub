# R19 A4 — 同じ都市一案の「実体建築・編集可能GLB」工程

**2026-10-31 JST。大方針は絶対不変：7.28km/約52秒級の本当に面白いSlope系高速実ゲーム＋圧倒的に美しい巨大未来都市を同一実走行に統合する。正式ART採用0件／Slope2 DNA認定0m／GAMEPLAY・HUMAN・PERFORMANCE・RELEASE・MERGE HOLD。**

## なぜ制作方法を変えるのか

R19 A3では巨大白壁と厚い棚に戻ってART REJECT。R19 A3Rでは背景が8〜11.5秒まで現れる構図は一部進歩したものの、今度は細い架台・門のような骨組みが中心で実体のある街ではないためART REJECT。これを単にフレームやモジュール数を増やして解決しようとするのは本来の方針に反する。

R19 A4では**同じRIFT CIVIC BASILICAを1案のまま**改修し、元実道路に対応する本物の体積・奥行き・開口を持つ建築翼と、編集可能な3Dモデルをまず成立させる。体積の3D表現と芸術的な完成とは区別する。

## 直接実装した変更

- 既存`scripts/p101-r19a3-one-integrated-civic-basilica-source.mjs`に`inhabitedBay`を設け、**実際の3D奥行きのある建築モジュール**（背面・左右側面・天井・地面／前方フレーム／3D奥へ後退したガラス面と返し壁）を生成。従来の線状フレームではない。
- 建築1案の中央大空洞を開いたまま、左右に複数階の建築翼を備える。4つの周辺地区にも、階高・後退・ボリューム・幅を異ならせた実体積モジュールを入れ、近景・中景・遠景で街と認識できるか原カメラで検査。
- 出口側road1の都市を保持し、road0/road1の４プログラムと主役建築を、**5つの別々の3D編集対象**に区切る。元の正規道路7本・動くB51 28基、球の物理・スピード・カメラ・HUDは変更しない。真アートの新コライダー0。
- 新規`scripts/p101-r19a4-export-editable-source-city-glb.mjs`で元W9-C1 ULTRA14mとCONTROL28mの真B48形状から**glTF2 GLB**を2件生成。各GLBは、ソース位置と頂点カラーの本物の3D三角形を持つ、5個の別名付きメッシュ/ノードを収録。開いて編集できるよう頂点位置と色を維持する。**Blender実アプリでの読み込み、マテリアル・ライティング・完成美術のQAは別途必要**。
- glTF 2のヘッダ、JSON/BINチャンク、float32位置・RGB属性、各5メッシュの領域、SHA256、元ソースGit Blob、未承認HOLDステータス、偽データ改竄拒否を`tests/p101-r19a4-editable-true-w9c1-gltf.test.mjs`で検証。
- 前工程のPRIVATEシーン`dist-private/r19a3`とソース元カメラの24画像・元240Hz同tickを**再利用**する。新たな撮影エンジン/大量ファイルを作らない。
