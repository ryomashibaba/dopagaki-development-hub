## 固定した原本と検査契約

GitHub Actions原本[K #41312758260](https://github.com/ryomashibaba/dopagaki-development-hub/actions/runs/41312758260)の**元WebGL2原画像30枚**とK3B [#41315509252](https://github.com/ryomashibaba/dopagaki-development-hub/actions/runs/41315509252)の**元WebGL2原画像28枚**、合わせて**真正PNG58枚**。各PNGの実バイト数と記録SHA256を直接照合し、同じ時刻に両記録が存在する12件（2道路幅×6ticks）のPNG SHAとソースRoad表示が一致することを検証。

**重要な記録系列の違い**：Kは前半13ticks×2幅をK3Bは後半8ticks×2幅として合計**21カメラ状態×2幅＝42状態**を構成する。ただしこれは**異なる収録系列を場面研究のため列挙したもので、1本の連続完走記録ではない**。後半との継ぎ目を滑らかな走行として捏造しない。空中フレームやRoad ID不明の位置を道路に割り当てない。

道路の源アンカーは各幅7×81標本の**本物のB48ソース由来データ**を使用。Road0〜6、7道路それぞれ異なるIDを持つこと、両幅とも対応道路で実際の元カメラ写真が最低1枚あることを確認。

## 研究対象（美術/遊べる空間ではない）

**全7道路×左右両側×沿道3仮位置**（u=.25/.50/.75、右／左道路端+70m）＝**42個の概念上の調査位置**。道路に関係なく近づく／離れる42個の真正カメラ状態それぞれから、42位置を測るため**42×42＝1,764件**の視点と位置の計測になる。

各仮位置は既存道路アンカーから求めた前方・外向き座標系に、20m×28mの**地面でもコライダーでもない仮の床四隅**と、仮の1.7m縦定規・仮の20m高さ開口定規を置く**計算だけ**。K2方式の1013×698／焦点係数1.35の近似投影で、画面内の四辺形面積、左右端のクリッピング、仮の前後奥行きの画面分離、縦定規の見かけの画面サイズを出す。画面が後ろ向きになる場合は「投影不明」とし、0/非可視と断言しない。

- `onScreenCourtAreaPx2`：カメラに投影できた概念的な四角形が**画面枠と交差する理論的な面積**。本当の中庭床・A5建築・B48/B51の手前後関係を判定しない。
- `depthSeparationFrontRearProjectedPx`：仮の床前縁／後縁の中点がスクリーン上でどれほど離れるか。**人が奥行きを感じるという実験値ではない**。
- `notionalHuman17mProjectedPx`：仮の1.7m定規の理論寸法。**ゲームに人が出たわけではない**。
- `notionalBackAperture20mHeightPx`：概念上の高さ20mの垂直な「抜け」の投影長。**建築の開口として成立したわけではない**。
- `screenCourtTotalAreaPx2`等：フラットな画面投影の面積。**元GPUの行列ではない**。具体的な建築位置をここから勝手に決定しない。

### 元ゲーム画面レビュー用の14枚の場面

各道路・各幅の真正実走カメラの**保存順中央の1時刻**を機械的に選び、1道路1枚の合計14原PNGを素材にする。幅ごとに7段の画像シート2枚を作成。背景は元A5の**本物のWebGL2画面**で、未制作の左右u=.50調査位置の黄色・水色の四辺形だけを、**描画後に数学的に注釈**する。スクリーンに収まらないときは見えないまま残し、偽の物体や見えないものを付け足さない。見やすい時刻を恣意的に選んで合格させない。

## 技術/ART判定、必須の不採用条件

**TECH限定PASSの条件**は、計測と原PNG SHA/元カメラ元Roadが全一致し、1,764測定行＋Road×幅14レビュー行＋2画像が揃い、原game source blob `af076d67492a677d2235e4730aef8cdf4808e106`、K4R凍結モデル `e653029771982b2c39ee2831ea19199f0704ddaa`などが不変なことのみ。独立ART審査・実建築施工・人間試遊はこの研究で合格にしない。

**不可解決点**：元A5・路面・B51の遮蔽を対象サイトの「実通路」の可視判定として検査していない。イメージ合計の画素が大きくても公共空間と理解されるとは限らない。区間間のカメラ記録の途切れを補間して実走連続動画と偽称しない。出力データはランキング・街区サイト正式推薦・新美術採用・FPS・SAT/CCD・HUMAN合格の根拠にしない。
