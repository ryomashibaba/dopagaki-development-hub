# DOPAGAKI W9-C1 G5-B 景観候補 — DRAFT / HOLD

## 固定方針
本件は既存の高速3Dゲームの継続。プレイヤーの楽しさ、実物理Slope系地形40%回復、巨大都市品質を優先する。W7F Gold / W9-X / B5 / main / 公開2サイトを保護し、明示承認なしにReady化・マージ・本番反映をしない。

## G5-Bの範囲
- web/p101-w9c1-g5b-skyline.mjs : W9-C1 CONTROL/ULTRA限定の読み取り専用GPU三角形。
- 明示指定 g5b=on の場合のみ表示。デフォルトOFF。URLのクエリとハッシュに対応。
- 道路端を直接サンプリングし、最低65m外側に大質量の建築・人工断崖・浮遊屋根・発光アクセントを生成。
- 7区間・28基の実衝突物、速度、操舵、カメラ、スコア、実B48道路は一切変更しない。
- 区間と左右で非対称に変化させ、単純な柱の規則反復を避ける。発光は寒色で障害物と区別する。
- 巨大都市構造ON/OFFトグルと連動。GPUの頂点浮動小数配列は240000未満、数値有限。
