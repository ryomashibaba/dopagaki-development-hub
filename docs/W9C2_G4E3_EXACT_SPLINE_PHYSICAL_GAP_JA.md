# W9-C2 G4E-3 — 原本の曲面・進路を壊さない実物理ギャップ

更新：2026-10-20。**独立候補・Draft/HOLD・公開/統合禁止**。

## 前工程の原因と修正
G4E-2は第IV道路を「元の31行×5列」から「切断前31行×5列 + 切断後31行×5列」へ**再サンプリング**していた。Catmull-Romの制御点間隔と端部補間が変わるため、元の走行可能な路面形状とガイドが一致しなくなった。実物理は37.183秒で離陸端の**107.041m手前**から脱落。切れ目を飛べないという証明ではなかった。

G4E-3では**原本の31×5制御点、元の7道路ID、7本の物理ガイド、routeSegments、全28移動障害物、spawn、正規B48 240Hz物理**をそのまま保持する。路面全体の形状を再計算しない。独立したG4E-1 SHOULDER候補の第IV道路にだけ、`voidLongitudinalCells`を指定する。

## 本物の物理空隙
- `private/reference_only/director/surface.js` の `tessellate` に任意指定の縦セル削除を実装。指定セルは路面の上面・下面・両側のスカート壁を**実際の衝突三角形から除去**し、切れ目の両端に厚みのある断面キャップを設ける。球をワープさせる、床を隠す、当たり判定を切り替える、速度を下げる処理はない。
- 指定セルの形式を厳密検証し、配列外・重複・逆順・極端な指定は拒否。指定のない全既存ステージは同一コード経路・同一三角形生成を維持。
- `web/drive3d.mjs` は将来のプレビューで衝突のない箇所を**見た目にも開口**する。路面と縁取り線をまたがせない（他の演出メッシュは個別監査が必要）。
- `scripts/p101-w9c2-g4e3-geometry-preserving-gap.mjs` は1〜3セルの短い空隙を独立生成。G4E-2の旧分割案はそのままHOLD。
- `tests/p101-w9c2-g4e3-real-gap.test.mjs` は原本の制御点・経路・28基完全一致、上面/下面の三角形欠損、端部キャップ、切れ目中央の床ゼロを検証。
- `scripts/p101-w9c2-g4e3-native-gap-matrix.mjs` はG4E-1 SHOULDER対照と1/2/3セルを、**全てstart00・52m/s・240Hz・P96既存補正操舵・実CCD**で比較。失敗を含む生の軌跡を保存。

## 判定基準
1. Gold/SHOULDERの正規start00完走が維持されること。
2. 実物理のギャップに接近し、空中へ離れ、別の実路面に着地すること（単に全編完走するだけでは不十分）。
3. 7区間全編を通過すること。
4. 人間操作、前方視認性、障害物回避の面白さ、FPSは**すべて未承認**。物理スクリプトPASSだけで正式採用しない。
5. Slope2 DNA 40%の達成認定距離は、実機人間QAとゲーム設計審査まで**0m**。

## 正規240Hz実測結果（修正版・2026-10-20）

[CI #39355747890](https://github.com/ryomashibaba/dopagaki-development-hub/actions/runs/39355747890) **SUCCESS＝検証プログラム成功、ゲーム走行合格の意味ではない**。全て実start00・52m/s・28基・既存P96補正操舵で実行。

最初の計測では「空中から一瞬道路に戻った＝着地」と判定していたが、**それは離陸前側の路面への一時接地**であり偽陽性だった。修正版では物理ガイドの正規化uを追跡し、離陸端u以上で空中へ出て、**着地端u以上で再接地した場合だけ**「着地YES」とする。現在の結果は全て**着地NO**。1セル候補はu=.52338で実離陸、2/3セルはu=.51202で実離陸。空中状態は確認できたが、危険な位置と速度での断面衝突を防げていない。

これにより、G4E-2の切断再サンプリングによる**離陸端107m手前での破綻**はG4E-3で解消した。一方、物理的な**自然着地は未達**。原本と同じスプラインを維持しても、任意の曲がり角に隙間を空けるだけでは着地できないことが判明した。

**G4E-3B次試験**：20m級の真の空隙を第IV道路の別のu=.40/.59/.70/.78に移して、自然飛行の軌道と断面衝突を比較する。補助ジャンプやワープを追加しない。

## 次の設計課題
実物理の自然ジャンプ・着地が成立した場合だけ、開口部の手前の予告表示と視認性、落下の危険性を高品質3D表示で評価し、ゲーム内の独立試走に進む。成立しない場合は実際の落下位置・速度・ギャップ寸法から形状と配置を再設計する。**人工着地・強制ジャンプ・速度リセットは禁止**。
