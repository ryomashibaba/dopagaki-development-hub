## なぜ高架接続案から設計を変えたか

G4E-4/5Aでは後半の第IV道路の実物理欠損から123m高架橋へ着地し、最大900mの下り道路も5.87秒間連続走行できた。しかし元の第V道路から700〜800m以上離れ、合流の単純Bezier曲線は170m/sで横加速度96.5〜118.9m/s²に達する（4056候補全て保守基準25m/s²を超過）。単純につないでも**7/7走破とは言えない**。

G4E-6では、比較的遅い序盤の**元の7道路の一部に実際の欠損を開け、その道路の着地側へ戻る構造**を最初から作る。第V道路を飛ばす別ルートを廃止。G4E-1 SHOULDERを介さず、凍結済みのW7F Gold原本を直接複製する。

## G4E-6D：ローカル限定の実WebGL手動比較

- スクリプト自動完走が成立した **C0-55-1 / B0-65-1** の2案だけを独立した試走候補として用意。
- `DOPAGAKI_G4E6_MANUAL=1 node scripts/build.mjs private` の場合に限り `dist-private/generated/` に2つのJSONを作る。**public/public-safeビルドには生成しない**。
- `127.0.0.1` または `localhost` の画面で `?g4e6=on` を指定した場合にだけステージ選択へ現れる。Goldや一般公開版の既定ステージは変更しない。
- `RUN_G4E6_LOCAL_QA.cmd` はWindowsでの1回起動用（Node導入済みが前提）。実行すると非公開ビルド・ローカルサーバー・ブラウザ起動まで行う。**Windowsでの実動作と人間の試走は別途確認が必要**。
- 試走JSONは候補ごとのIDでローカルダウンロードする。自動送信なし。項目は速度感、操舵感、障害物の視認性・自由記述など。
- `web/p101-a13-road-art.mjs` のGPU専用シェブロンをギャップ前後だけ除外して、**見た目の飾りが物理的な穴を橋渡しする誤表示**を防ぐ。
- [Chromium専用CI](https://github.com/ryomashibaba/dopagaki-development-hub/actions/workflows/p101-w9c2-g4e6d-private-webgl.yml) で、プライベートビルドの実WebGL、URL opt-in、正式Goldの既定選択、2候補の独立ロード、公開用ビルドにギャップJSONが存在しないことを検証。
