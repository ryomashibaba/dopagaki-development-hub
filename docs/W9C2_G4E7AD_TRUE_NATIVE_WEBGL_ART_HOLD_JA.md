# G4E-7AD — 実240Hz走行カメラによる高速3D視界の独立比較

基準日：2026-10-23 JST。Draft PR #46。比較対象はG4E-7AC R2の実B48全7道路自動完走2案。正式認定0m、人間・美術・公開HOLD。

現行の研究用コース2案をローカルWebGL2に出力し、実start00/52m/s/240Hz/28基の移動障害物/P96研究操舵で得たカメラを再現する。タイムスタンプ3.15/3.65/4.15/4.50/5.15/6.00秒。実プレイヤー操作ではない。

別の視覚研究案では本物のB48路肩から60m以上外側に、非対称で空洞をもつ巨塔12本を配置。人工ジャンプ、ブースト、着地床、衝突面は追加しない。道路・ギャップ・着地先の視認性改善は未認定。

privateビルドかつDOPAGAKI_G4E7AD_VISUAL=1のときだけ生成される研究用JSON。localhostで g4e7ad=on / g4e7adFrame=hold を指定する場合にのみ選択可能。g4e7adScene=city または clear で視界比較。publicおよびpublic-safeビルドでは候補JSONを生成しない。

CIは2形状×3時点×都市の有無でWebGL2画像12枚を保存し、物理の7道路・28動体・真の欠損セル52・カメラ同一性・非衝突性・公開隔離を照合。WebGL画像を取得できたことは美術・人間の遊びやすさの合格ではない。CIの実測結果を確認してから判定を追記する。
