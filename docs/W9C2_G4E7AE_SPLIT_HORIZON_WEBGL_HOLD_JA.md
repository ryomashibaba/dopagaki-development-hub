7ADで実240Hzの遠方視認性は`approach-arc`が優位（168m眼→踏切時点で真B48遮蔽0/6）。一方、WebGL実画像の従来ゲートと箱の繰り返しが画面を支配し、7AD追加12塔の画面変化は弱かった。

7AEでは単なる塔の追加を禁止し、研究用URLの `g4e7aeScene=rift` で従来の`scenery` / `megaWorld` / `a13ArchMesh` / `g4dSkywayMesh` / G5-B skyline / 7AD towerを**描画から除外し、代わりに2つの連続的な巨大都市断層の実3D曲面メッシュへ置換**。base `legacy` は同じ実物理/カメラで元の景観を表示する比較用。

新メッシュは実B48第一道路の左右路肩を始点とした曲面帯、変化する稜線・傾いた層・大きな抜け空洞・折れた都市外殻。長さは第一道路正規u=0.055〜0.925。約36サンプル×10高度層×左右2岸。非対称、スパンの中央を横断しない、道路の外側55m以上を維持する設計。物理B48や障害物には提供しないGPU専用頂点。
