# G4E-7I 非公開実WebGL可読性・SKYLINE路肩の美術研究
研究日: 2026-10-22 JST、対象: Draft PR #46 / `p101-velocity-overdrive-native-trial`

## 変更の狙い
G4E-7H（実WebGL画像8枚）で前方HUD矩形占有率は14.42%→0.55%まで下がったが、警告字のサイズ10pxが小さく、高速時の読みやすさは認定できない。今回のG4E-7Iは「視界を塞がず、情報は削らず、文字を読みやすく」という衝突する要求を独立試験する。

- `G4E-7H FOCUS` をユーザーが明示的に選択した上で、さらに `G4E-7I` トグルを有効化。警告文字を10px→12.5px、道路端も10px→12px、文字を折り返して省略しない。モバイルも12px以上。
- 物理的に7/7走破した `glide` の道路I / u=.49–.652に、既存のB48衝突路面上にある左右の縁をなぞる **13区間×左右2本＝26個**の短い光学パッチを追加。中央の推奨安全レーンは描かない。実物理に存在しない新床、橋、障害物、ジャンプ補助、操舵は一切なし。
- 発動は `127.0.0.1/localhost` かつ `?g4e7g=on&g4e7h=candidate&g4e7i=candidate` の非公開GLIDE比較ステージのみ。G4E-7D手動ギャップ、Gold、既存G4E-7H単独モード、通常プレイは全て現状維持。
- BASELINEとLEGIBLEの同一物理時刻0秒・同一Runnerカメラ位置における実WebGL比較を2地点＋モバイル1視点で実施する。DOM警告文の完全一致、ステージ/スポーン/モード/28基/タイムの完全一致、WebGL画素変化、CSS警告フォントの大きさ、DOM警告の可視性を検証。ROIはG4E-7Hと同じ6–94% / 25–92%だが、警告を大きくした分だけ前方HUD占有率が高くなる可能性を正当に計測。
- 非公開の試作品・未採用。非公開GLIDEはスクリプト240Hzで7/7を既に完走したが、G4E-7IのWebGL比較で人間の読み取り時間・楽しさ・端の判別率は計測できないためHOLD。

Gold/W7F、G5-C1、球の相対カメラ固定、28 B51-C実移動障害物、B48コリジョン、速度/スコア/操舵、本番2サイト、mainは無変更。今回の標本は実WebGLの静止画像であり、人間のレース走破とは異なる。正式Slope DNA認定0mを維持。品質が不十分ならトグル実験のまま残し、正式採用しない。
