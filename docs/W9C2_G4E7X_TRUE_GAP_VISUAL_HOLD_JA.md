## 2. G4E-7Xの追加した**非物理**の見通し案

`web/p101-w9c2-g4e7x-gap-reading.mjs` は正確な15.76m実B48欠損セル52と、物理的に全道路走行を確認した2候補だけを厳格に許可する。元物理/路面/経路/カメラ/28移動機械/非人間操舵の変更は **0**。

見た目の変更のみ：

- 本物の踏切から道路中心線の弧長をさかのぼり、**195m・145m・95m・50m・20m・5m**前に細い切れ切れの警告ライン。100m/sなら195mは約1.95秒の距離に相当するが、人間が実際に見つけられるかは画像・手動検証が必要。
- 最後の約75mを、道路の**外縁の上だけ**に小さな断続的な縁取りを置く。永続的な中央安全帯、橋、巨大な視界遮蔽物は追加しない。
- 本物の着地端から少し下流だけに薄い小さな進行方向ライン。**飛行空間そのものには0個の三角形**。単なる光線の橋や架空の接地床として偽装しない。
- 実路面の`sample`と`frame`にGPU三角形を追従。マテリアル・透明床・衝突・見えないヘルプ床はゼロ。実ギャップを隠す既存P100/W8/B5ペイントの抑制も継続。
- 専用研究localhostページでのみ `g4e7w=on&g4e7wFrame=hold&g4e7xGuide=on` かつ正しいαのとき表示。OFFでは元画像のまま。既存の本番ゲームとスコア保存には無関係。

同じ実240Hzのカメラと速度で**マーカーOFF/ONを20画像**（α=0.65/0.70 × 5時点 × 2条件）撮影する専用Playwright試験を追加。全20条件でコースID/物理道路7本/動体28基/実幅/実ギャップ/記録速度一致を要求。候補の見た目が向上したかは、実画像を目視審査して別途判定する。
