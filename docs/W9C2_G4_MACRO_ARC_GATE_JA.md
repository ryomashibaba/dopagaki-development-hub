# W9-C2 G4 / G4B — 巨大MACRO-ARC 実物理研究ゲート

## 目的・保護条件
前工程のW9-C2 G2/G3Bは、203mの小区間へ急なS字・隆起を詰め込み、150〜205m/sで落下した。G4は全長1,800mの既存第IV道路（LOWER_REVERSAL、元から180°の巨大カーブ）へ実際のB48道路変形を加える独立研究。W7F Gold、B5、W9-C1、W9-X、P100、main、実サイト、G5-C1の好評だった非致死衝突復帰を変更しない。PR #46はDraft、HOLD、非公開。

## 実装
- `scripts/p101-w9c2-g4-macro-arc-build.mjs`: 本物の31×5 B48物理格子の第IV道路を横に大きく変位させ、緩やかな立体隆起とバンクを作成。u=.06〜.94の約1,584mを変形。両端の接続・ほか6道路・正規6スポーンを保全。
- G4 SWEEP: 横変位スケール78m、隆起15m、道路幅目標83m。G4 SKYLINE: 110m、23m、75m。
- G4B GLIDE: 横変位スケール35m、隆起2.5m、道路幅目標115m。G4B HORIZON: 52m、4m、105m。**G4BはG4を上書きせず別オフライン候補として追加。**
- 第IV道路に置かれた**実動体6基**の中心位置を旧路面から新路面へ正しく移し、スライダーの水平方向も新路面に合わせて回転。28基すべての障害物種別・サイズ・周期・位相・衝突モードを保持。旧機械の座標まで同じとは偽らない。
- 道路以外の物理、240Hz Runner、速度加速、ジャンプ、カメラ、スコア、衝突処理は無変更。
- 新候補は**ゲームのセレクターには未登録**。通常プレイで選択不可、公開なし。

## 品質判断
小さく・平坦にするだけで合格を作ることは目標と違う。元から1,800mの180°カーブを持つ道路に上乗せしたG4Bの追加変位が、実際のプレイヤーに新しい操作・爽快感・見た目のインパクトを与えるかは画像・人間QAで確認する。通過しただけで採用しない。合格距離をSlope DNA 40%へ加算しない。

別途、フルCIのブラウザjobはChromiumインストール環境で失敗した回がある。QAジョブ成功とブラウザ実描画成功を混同しない。

## 次の設計判断

G4・G4Bの4案はすべて研究用HOLD。今後は第IV道路の既存180°カーブと高速度の連続走行を尊重し、**道路中央線を強引に左右へ蛇行させるより、元の巨大会場カーブに沿う別高度の立体道路・大きな交差・外殻のシルエットを検討**する。必要なら第IV道路自体ではなく次の道路区間に別の大きな形態を配置し、同じ自然スタート00で物理完走が成立するか評価する。

G4Cの正規スタートでも操舵は人間ではなくP96スクリプト。仮に完走しても、手動操作の楽しさ・視界・画面品質は別ゲート。今回の候補について完成距離は0m、40%目標へ加算しない。B5/Gold/既存W9-C1・W9-X/G5-C1の復帰係数と本番サイトは不変。
